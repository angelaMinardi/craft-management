# PatternVault TikTok Shoot Plan

Goal: capture enough raw footage in one weekend to edit 5–8 short-form videos (9:16, 15–45s each). Shoot everything vertical. Record app audio separately — you'll layer trending sounds/VO in post.

## Core hooks to film (pick 5–8)

Each hook = one video. Shoot the hook line twice (one energetic, one deadpan) so you have options in the edit.

1. **"POV: you used to lose your place every other row"**
   → Cut to: voice row counting in action. Say a row number, watch it update.
2. **"Things my knitting app does that shouldn't be legal"**
   → Rapid-fire: share from Ravelry, AI step parsing, chart mode, voice counter.
3. **"I built an app because I was tired of [losing patterns / counting stitches / tangled stash]"**
   → Origin story. Show the pain, then the fix.
4. **"Save any pattern on the internet in 3 seconds"**
   → Screen record: open Ravelry → share sheet → SaveToPatternVault → pattern appears.
5. **"Knitters, tell me you don't need this"**
   → Interactive chart mode, zooming/panning, tapping rows.
6. **"My yarn stash is finally organized"**
   → Beauty shots of yarn → app stash view with the same skeins.
7. **"Connect your Ravelry library in one tap"**
   → Settings → Ravelry → import running → library populated.
8. **"Hands-free knitting tech"**
   → Hands busy knitting, voice says "row 42", phone updates on its own.

## Shot list — knitting footage (b-roll)

Film all of these once; reuse across videos.

- [ ] Close-up hands knitting, 30s continuous (ASMR)
- [ ] Close-up hands knitting, top-down angle, 30s
- [ ] Needles clicking — audio-focused, clean take
- [ ] Yarn ball unspooling as you knit
- [ ] A finished swatch / WIP laid flat (beauty shot)
- [ ] Yarn stash pile, overhead — slow pan or static
- [ ] A printed paper pattern, crumpled / covered in notes (the "before")
- [ ] Phone propped up next to knitting, screen visible
- [ ] You picking up the phone mid-row to check something

## Shot list — app footage (screen recordings)

Use iOS built-in screen recorder. Keep each clip tight (5–10s). Re-record rather than trim long takes.

- [ ] Share from Ravelry → pattern lands in vault with "Processing..." → enriched
- [ ] Pattern detail view, scrolling through AI-parsed steps
- [ ] "Analyze Steps" wand button → parsed steps appear
- [ ] Interactive chart grid: zoom in, tap a row, advance rows
- [ ] Voice row counting: tap Row → say number → progress updates
- [ ] Yarn stash list scrolling
- [ ] Find Patterns (Ravelry search) → enter yarn weight → results
- [ ] Ravelry OAuth connect → "Import my library" → patterns populate
- [ ] Dashboard / home screen — the "hero" shot of the app
- [ ] Adding a project note with a photo

## Shot list — talking / face (optional but helpful)

Only needed for hooks 1–3, 6. Film in good natural light, phone at eye level.

- [ ] Each hook line, 2 takes (energetic + deadpan)
- [ ] One "ugh" / frustrated reaction to the pain point
- [ ] One satisfied / relieved reaction to the fix
- [ ] B-roll of you actually knitting while looking at phone

## Editing notes (for video-use)

- Target aspect ratio: **9:16 vertical** — specify explicitly, tool defaults aren't TikTok-native.
- Lead with the payoff in the first 1 second. Hook line can overlay while the satisfying visual plays.
- Keep cuts fast: 0.5–1.5s per shot in feature showcases.
- Burn subtitles — most TikTok viewers watch muted.
- Save project files per-video so video-use retains editing memory.

## Don't forget

- Charge phone, clear storage (screen recordings are huge).
- Clean the camera lens.
- Film in landscape? **No.** Vertical only.
- Get a clean shot of the app icon / launch screen for outros.
- Record one "follow for more knitting app tips" outro you can reuse.
