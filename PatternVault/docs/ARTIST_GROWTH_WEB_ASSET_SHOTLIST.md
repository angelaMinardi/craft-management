# Growth + Web Asset Shot List

Use this shot list for the second production wave after core mascot assets are approved.

## Purpose

Deliver endearing visuals for celebration, recovery, sharing, and web conversion surfaces while staying lightweight and reusable.

## A) Celebration Asset Pack

## Required badge/sticker assets

- `badge_first_save`
- `badge_first_import`
- `badge_first_completion`
- `badge_streak_3`
- `badge_streak_7`
- `badge_streak_30`

Each badge needs:

- Full color version
- Monochrome fallback version
- Transparent PNG export

## Decoration overlays

- Confetti overlay (light)
- Confetti overlay (medium)
- Sparkle accent cluster
- Ribbon/banner accent

Constraints:

- Must not interfere with text legibility.
- Avoid dense particle fields.

## B) Recovery + Empty-State Pack

## Empty states

- Empty dashboard support illustration
- Empty pattern list prompt illustration
- No results/search illustration

## Recovery states

- Offline/retry supportive pose
- Import failed but recoverable supportive pose
- Generic error reassurance pose

Tone rules:

- Empathetic and calm, no exaggerated sadness.
- Always pairable with action-oriented copy.

## C) Share-Card Decoration Pack

## Required frame variants

- Completion celebration frame
- Progress milestone frame
- First pattern saved frame

## Required decorative elements

- Corner flourishes
- Yarn/thread accents
- Small mascot cameo variant (optional/enable-disable)

Export notes:

- Keep safe area around center content.
- Avoid heavy top overlays that clash with text.

## D) Website Conversion Visual Pack

## Hero system

- Primary hero illustration (mascot + craft world)
- Alternate hero for compact viewports
- Hero accent elements (separable layers)

## How-it-works mini-illustrations

- Step 1: Save/import pattern
- Step 2: Organize and track progress
- Step 3: Celebrate and share

## Trust/support visual set

- Privacy-first icon
- Support/help icon
- Craft community icon

Constraint:

- Trust visuals must remain qualitative unless claims are independently verified.

## Delivery Naming Convention

- `growth_badge_<name>_v1.png`
- `growth_overlay_<name>_v1.png`
- `recovery_state_<name>_v1.png`
- `share_frame_<name>_v1.png`
- `web_hero_<name>_v1.png`
- `web_howitworks_<step>_v1.png`
- `web_trust_<name>_v1.png`

## Approval Gates

The growth + web pack is approved only if:

- All categories above are complete
- Small-screen readability is preserved
- Text-safe zones are respected
- Asset naming is consistent
- Palette/tone remains brand-compliant
