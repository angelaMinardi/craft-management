# Acquisition Creative Briefs

Use these templates to produce ad creative that matches real in-app moments.
Every brief must map to one intent cluster, one creative family, and one first-session win.

## Global Constraints

- Preserve existing brand palette and mascot personality.
- Keep claims aligned with in-app behavior and current store/web copy.
- Do not use manipulative urgency, deceptive discount framing, or incentivized review language.
- Include attribution confidence tier in analysis notes after each test run.

## Creative Family 1: Mascot Emotion Hooks

### Goal

Create an emotional onboarding bridge before heavy setup by showing the mascot move from chaos to calm.

### Recommended Angles

- "Too many saved pattern tabs?" -> mascot overwhelmed -> calm vault moment.
- "Inspiration everywhere, zero system" -> mascot finds one home for all links.
- "I will make this someday" -> mascot nudges first quick save.

### Asset Pattern

- 0-2s: emotional pain cue
- 2-6s: mascot reaction and identity moment
- 6-12s: quick save demo
- 12-15s: calm payoff + CTA

### First-Win Mapping

- Best mapped event: first pattern saved from share flow.

---

## Creative Family 2: First-Win Workflow Demos

### Goal

Show concrete product value in one tiny workflow users can repeat.

### Recommended Angles

- Save pattern from social/web in two taps.
- Move pattern to "In Progress" and add one project note.
- Add stash/tool item and connect it to next project.

### Asset Pattern

- 0-3s: context setup (where pattern is discovered)
- 3-10s: tap-by-tap workflow
- 10-15s: finished state and emotional payoff

### First-Win Mapping

- Best mapped events: onboarding complete -> first meaningful action.

---

## Creative Family 3: Payoff/Organization Outcome Reels

### Goal

Show downstream calm and consistency, not just feature clicks.

### Recommended Angles

- Before/after: scattered links vs organized vault.
- Weekly progress: small wins compounding into finished projects.
- "Future me" value: notes/materials ready when resuming.

### Asset Pattern

- 0-4s: disorganized pain montage
- 4-10s: organization transformation
- 10-15s: retention payoff (continue where you left off)

### First-Win Mapping

- Best mapped events: progress updates, repeat sessions, D7 retention quality.

---

## Post-Launch Review Checklist

- Did the creative attract the intended cluster?
- Did install-to-activation improve for that cluster?
- Did conversion/retention remain healthy under guardrails?
- Was confidence tier sufficient for scale decision?
- What copy should sync into store/onboarding/paywall next?
