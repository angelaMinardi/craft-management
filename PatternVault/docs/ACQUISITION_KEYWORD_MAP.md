# Acquisition Keyword Map

This is the canonical ASO keyword and intent-cluster map for Corvid Craft.
It ties acquisition intent to store messaging and first in-app value moments.

## Attribution Reality and Confidence

- Use best-available attribution only; do not claim deterministic user-level source mapping when platform constraints prevent it.
- Every report slice must include a confidence tier:
  - `high`: source and campaign reliably available for the slice
  - `medium`: partial source signal with stable directional consistency
  - `directional`: inferred/modeled or sparse mapping; use for trend signals only

## Intent Clusters

### 1) Beginner Pattern Organizer

- **User intent:** "I keep losing patterns and need one simple place."
- **Primary emotional hook:** relief and clarity in first session.
- **In-app first win:** save first pattern and set status.

**Primary keywords**
- pattern organizer
- crochet pattern organizer
- knitting pattern organizer
- craft pattern tracker
- pattern library app

**Secondary keywords**
- organize crochet patterns
- organize knitting patterns
- project tracker for crochet
- project tracker for knitting
- craft notebook app

**Store line candidates**
- Save every pattern in one private vault.
- Organize by status: Want to Make, In Progress, Completed.
- Built for crafters who collect more patterns than they can make.

### 2) Stash/Tool Planners

- **User intent:** "I want to plan projects using yarn, hooks, and needles I already own."
- **Primary emotional hook:** confidence and control before starting.
- **In-app first win:** add stash/tool item and match it to a pattern.

**Primary keywords**
- yarn stash tracker
- knitting needle tracker
- crochet hook tracker
- craft supplies tracker
- knitting planner app

**Secondary keywords**
- yarn inventory app
- project planning for crochet
- project planning for knitting
- craft stash organization
- yarn and pattern planner

**Store line candidates**
- Track stash and tools beside each pattern.
- Plan your next make with what you already own.
- Keep notes, materials, and project details together.

### 3) Save-from-Web/Social Utility Seekers

- **User intent:** "I discover patterns everywhere and need quick capture."
- **Primary emotional hook:** never lose inspiration again.
- **In-app first win:** save from share sheet URL in two taps.

**Primary keywords**
- save pattern from web
- save crochet pattern link
- save knitting pattern link
- pattern saver app
- craft bookmark app

**Secondary keywords**
- save from tiktok
- save from youtube tutorials
- save from ravelry
- save from etsy patterns
- pattern link organizer

**Store line candidates**
- Save from Ravelry, Etsy, TikTok, YouTube, and blogs.
- Capture pattern links in two taps from the Share Sheet.
- Keep every idea in one searchable vault.

## Campaign Taxonomy Linkage

Each keyword cluster must map to:
- one creative family (`mascotHook`, `firstWinDemo`, `outcomeReel`)
- one onboarding promise
- one first-session activation event
- one paywall narrative (if shown)

Do not launch a new keyword group unless all four mappings are defined.

## Weekly Operating Rules

- Promote keyword sets only when activation quality holds in `high` or `medium` confidence slices.
- For `directional` slices, require two consecutive weekly readouts before scaling spend.
- Deprecate keywords that show weak activation or retention, even if CPI is low.
