# Artist Style Frame Review and Direction Lock

Use this document to evaluate initial artist concepts and lock one direction before full production.

## Review Goal

Select one style direction that best expresses Corvid Craft's emotional positioning and can scale across app, extension, and web surfaces.

## Submission Requirements (Artist)

Artist submits 2-3 style frames plus one expression sheet concept for each direction.

Each direction must include:

- Mascot in onboarding context
- Mascot in success/celebration context
- Mascot in recovery/error support context
- One web hero adaptation crop

## Scoring Rubric (100 points)

- Emotional clarity (25)
  - Can users read the feeling in under 1 second?
- Brand fidelity (25)
  - Does it feel like Corvid Craft's current palette and personality?
- Product fit (20)
  - Does it integrate cleanly with rounded UI and text-heavy surfaces?
- Reusability (15)
  - Can this scale into expressions, scenes, and badges without rework?
- Technical feasibility (15)
  - Is complexity realistic for lightweight iOS + extension constraints?

Minimum passing score to proceed: 80/100.

## Hard Rejection Criteria

Reject immediately if any are true:

- Palette drift outside approved brand colors
- Mascot silhouette/proportions no longer recognizable
- Style feels overly juvenile or too game-like for utility app usage
- Requires heavy motion systems not supported by current app architecture

## Review Process

### Step 1: Async scoring

- Each reviewer scores all directions independently.
- Reviewers include: Product/Design lead, Design Systems pod lead, Core pod rep, Extension/Web pod rep.

### Step 2: Calibration session

- Discuss top two candidates.
- Resolve score gaps larger than 10 points per category.
- Confirm small-screen legibility with mock placement checks.

### Step 3: Direction lock

- Choose one primary direction.
- Optionally preserve one backup direction as contingency.
- Document exactly what is locked and what remains flexible.

## Artist Feedback Package (After Decision)

Send the artist:

- Winning direction summary (1 paragraph)
- Keep/change list
- Priority production order (P0/P1/P2)
- Notes on text-safe zones and small-size legibility
- Technical export reminders from `MASCOT_ASSET_HANDOFF.md`

## Ready-for-Production Gate

Direction is considered locked only when:

- Decision record is complete
- All required sign-offs are present
- Keep/change list is sent to artist
- No unresolved blockers remain
