# Acquisition Pod Kickoff Packet

This packet is the fast-start guide for launching Acquisition Pod operations.
Use it to run the first two weeks with clear ownership, guardrails, and deliverables.

## Mission and Scope

### Mission

Scale high-intent growth by connecting product moments to ASO and paid acquisition strategy.

### Scope Boundary

- Acquisition owns strategy, taxonomy, experiment design, and weekly readouts.
- Core/Growth/Extension-Web own implementation scope, technical feasibility, and release timing.
- All analysis must use best-available attribution with confidence tiers.

## Week 0 Setup Checklist (Before First Live Test)

- [ ] Confirm ownership roster and weekly meeting cadence.
- [ ] Confirm source docs are accessible to all pod members.
- [ ] Confirm experiment registry is created and seeded.
- [ ] Confirm campaign taxonomy naming is adopted in active channels.
- [ ] Confirm message sync matrix has initial active rows.
- [ ] Confirm compliance preflight reviewer(s) are assigned.
- [ ] Confirm stop-loss thresholds and escalation contacts.

## First Two-Week Execution Plan

### Week 1 (Foundation + First Launches)

- Build 3 intent-cluster campaign drafts:
  - `beginnerOrganizer`
  - `stashPlanner`
  - `saveFromWeb`
- Prepare one creative per family:
  - `mascotHook`
  - `firstWinDemo`
  - `outcomeReel`
- Score candidate tests with ICE/RICE.
- Launch up to 3 non-overlapping tests (concurrency cap).
- Publish first weekly growth readout with confidence notes.

### Week 2 (Signal Validation + First Handoffs)

- Evaluate early winners/losers with guardrail checks.
- Pause or rollback tests that breach stop-loss for two windows.
- Propose first product recommendations to relevant pods.
- Sync winning messages into store/web/in-app via handoff packets.
- Publish second weekly readout and decision log.

## Weekly Meeting Cadence

### 1) Monday Readout Prep (30 min)

- Review funnel scorecard by channel/cluster.
- Confirm confidence-tier labels and caveats.
- Flag any stop-loss risks.

### 2) Tuesday Prioritization (45 min)

- ICE/RICE scoring review for next tests.
- Confirm concurrency limit and audience isolation.
- Draft handoff recommendations.

### 3) Wednesday Cross-Pod Review (45 min)

- Present recommended changes and evidence strength.
- Confirm pod ownership, feasibility, and release windows.
- Capture accepted/deferred/rejected decisions.

## Preflight and Guardrails

### Compliance Preflight Trigger

Run preflight before any test touching:
- review prompts
- subscription framing
- urgency language
- discount presentation

### Stop-Loss Trigger

Escalate and rollback/pause when canonical thresholds breach for two consecutive windows.
Canonical threshold source:
- `docs/ACQUISITION_EXPERIMENT_REGISTRY_TEMPLATE.md`
